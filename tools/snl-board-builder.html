How to use this

  1. Set the board name and how many squares it has.
  2. Click a square, pick what it does, and search for the OSRS items it accepts.
  3. Clear everything listed under Checks — the bot rejects a board with errors.
  4. Press Download board JSON, then upload that file with /snl setup in Discord.
  5. Optional: Download board picture gives you a PNG of the board. Put it somewhere permanent (Imgur, for example) and pass the link to /snl setimage so it shows in the game messages. Discord's own attachment links expire, so don't use those.

Your work is saved in this browser automatically, so you can close the page and come back to it.
